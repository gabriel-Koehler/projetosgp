# N1-FE-02 — Semestres e turmas

Branch derivada de feat/n1-be-02-python-mock-state-v2.
Listagem de semestres com situação e contadores; cadastro em modal; cards de turmas vinculados ao semestre; detalhes com alunos e link de retorno.
Filtros e turma ficam na URL, preservando navegação e recarregamento.
Dados são fornecidos pela API Python em memória existente.

Validação no navegador: cadastro de semestre e turma, semestre vazio, filtro, vínculo correto, detalhes, recarregamento, retorno e viewport mobile 390×844 sem overflow.
