# N1-FE-07 — Correção simulada e estatísticas

Issue #14. Base: feat/n1-fe-06-impressao-prova-aluno, commit 3cfa132.

## Fluxo
1. Em Correção Automática, selecione avaliação, aluno e versão.
2. Selecione PNG, JPEG ou PDF até 10 MB e clique em Simular leitura, ou escolha entrada manual.
3. Confira as alternativas A–D, marque a confirmação e salve. O resultado leva à página de notas.
4. Filtre avaliação/aluno; confira cada resposta, exporte CSV ou imprima. As estatísticas mostram percentual de acertos e alternativas mais marcadas, incluindo empates.

A simulação gera escolhas independentes do gabarito e não interpreta o arquivo. O arquivo permanece no navegador; somente respostas revisadas são enviadas ao mock Python. Trocar aluno/versão descarta a revisão anterior. A API rejeita correções duplicadas.

## API
GET /api/avaliacoes/{id}/estatisticas aceita student_id opcional. A agregação usa o identificador original da questão e os índices originais das alternativas salvos no snapshot de cada versão, inclusive quando os textos são idênticos. Não depende do banco de questões atual. Sem resultados, média e percentual retornam null.
