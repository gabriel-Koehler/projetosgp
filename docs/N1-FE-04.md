# N1-FE-04 — Banco de questões

CRUD com enunciado, disciplina, dificuldade, alternativas A–D e gabarito. Edição preserva snapshots das avaliações existentes. Filtros combinados de texto, disciplina e dificuldade. Alternativas recolhíveis e gabarito sempre visível.

Importação CSV UTF-8 por modelo /modelo_questoes.csv (8 colunas, 1 MB, até 500 linhas), com prévia e erros por linha. Somente as linhas válidas são confirmadas; servidor valida duplicidades e não grava lote parcialmente.

Endpoints adicionados: PUT /api/questoes/{id}, POST /api/questoes/import.

Validação: testes Python de atualização/snapshot/importação atômica; testes CSV de aspas, formatos e duplicados; navegador desktop/mobile para CRUD, filtros, modelo e importação. Planilhas XLSX devem ser exportadas como CSV.
