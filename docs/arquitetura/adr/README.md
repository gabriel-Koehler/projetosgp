# Architectural Decision Records (ADRs)

Este diretório contém os **Registros de Decisões Arquiteturais (ADRs - Architectural Decision Records)** do **Sistema de Geração e Correção Automática de Avaliações (SGP)**.

As decisões seguem o formato padronizado de registros técnicos (baseado no formato Michael Nygard / MADR), documentando o contexto, as alternativas avaliadas, as razões da escolha e as consequências positivas e negativas de cada decisão.
