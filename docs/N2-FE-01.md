# N2-FE-01 — Autenticação, semestres e turmas persistentes

Issue #22. Branch: feat/n2-fe-01-integracao-auth-turmas. Base: feat/n2-api-auth-turmas (PR #60), que reaproveita a API dos PRs #40–42.

## Entrega
- Login por usuário/senha na tabela professor, sessão HTTP-only, logout e retorno ao login quando a sessão expira.
- Semestres: criar, editar nome/datas, ativar e desativar.
- Turmas: criar, editar nome/disciplina/semestre e excluir. Duplicidade e vínculos que impedem exclusão aparecem como erros na tela.
- Estados de carregamento, vazio, falha de conexão, validação e botão de tentar novamente; formulário mantém os dados digitados em caso de erro.
- Layout AvaliaSystem em desktop e celular. No modo real, a navegação apresenta apenas os módulos já conectados; o modo N1 continua disponível separadamente.

## Executar com Supabase
1. Instale as dependências: npm install e python -m pip install -r requirements-dev.txt (use a .venv).
2. Configure o .env local com DATABASE_URL, SECRET_KEY e PROFESSOR_USERNAME/PROFESSOR_PASSWORD/PROFESSOR_NOME. Veja .env.example. DATABASE_URL é a conexão PostgreSQL do Supabase; use sslmode=require e a porta indicada pelo projeto/pooler. Credenciais ficam somente no Python, nunca em config.js.
3. Em um banco de desenvolvimento autorizado, aplique o schema e o professor inicial: python -m app.database.migrate. O professor existente não tem a senha sobrescrita.
4. Verifique a conexão: python -m app.database.check.
5. Execute npm run dev:real e abra http://localhost:3000. O launcher inicia app.persistent:create_app em 8000 e configura o frontend para os contratos reais. Para uma API remota já existente, execute o Express com DATA_MODE=real e API_TARGET apontando à origem da API.
6. npm run dev:all continua executando o MVP N1 em memória.

## Contratos
O adaptador converte username/nome e identificadores numéricos da API para os campos da interface. A API de semestres recebe nome/data_inicio/data_fim; turmas recebem nome/semestre_id/disciplina. O campo antigo de código da turma não é enviado como disciplina implicitamente. Respostas 204, erros detail/422 e indisponibilidade são tratados. O proxy mantém cookies na mesma origem.
