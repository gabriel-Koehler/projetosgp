# Fluxo de trabalho deste repositório

Instruções do responsável pelo projeto:
- Ao iniciar uma nova issue, crie a branch indicada pela issue a partir da branch mais atual da última issue executada, preservando todas as entregas anteriores. Não voltar à main automaticamente.
- Conclua e valide a issue atual antes de iniciar a seguinte.
- Faça commits semânticos e push ao concluir etapas importantes. Abra PR para a branch da entrega anterior e indique dependências. Não faça merge sem autorização.
- Mantenha o visual AvaliaSystem existente.
- Atualize docs/ACOMPANHAMENTO_ISSUES_GABRIEL.md a cada issue realizada: implementação, validação, branch, commit/PR e pendências. Consulte o estado real do GitHub antes de marcar merge/encerramento.
- Diferencie implementação entregue, PR aberto, merge e issue encerrada. Não marque concluída uma issue apenas porque há um fluxo parcial no MVP.
